## 01 - 5V LED Indicator

A compact SMD indicator circuit designed for automated PCB fabrication.

### Specifications
* *Operating Voltage:* 5 V
* *Current-Limiting Resistor:* 300 Ω (0805 SMD)
* *Indicator:* High-Efficiency LED (0805 SMD)
* *Layer Count:* 2-Layer FR4
